# XpertAcademy

XpertAcademy has free courses at [xpertcreation.com/academy](https://xpertcreation.com/academy/).

## Courses
- **Microsoft Office:** Word, Excel, PowerPoint, VBA
- **Programming:** Python, JavaScript, Django, React, Blockchain basics, and the **live project**: build and launch a full-stack Task Board with Python, Django and React
- **Languages:** Korean, Japanese, Turkish, German, French, Norwegian
- **Exams:** IELTS preparation
- **Quran:** Al-Quran

## How lessons work
Each course is a series of lessons. You can link straight to a lesson, for example `/academy/?c=python&l=3`.

In the programming courses some lessons contain code you can **run in the page**: HTML, JavaScript, Python and React. Python loads once (about 6 MB) and then runs on your own device. Code boxes show their language (Python, Terminal, JSX…) and have a **Copy** button.

## Suggested path for developers
Python → JavaScript → Django → React → the live project. Finish the live project and share it on XpertConnect with **#XpertAcademyProject**.

In the language courses, tap words in Korean, Japanese, Chinese or Arabic script to hear them spoken.

## Community videos
Members can suggest YouTube or Vimeo videos for a course. They are checked before they appear.
