# XpertCreation guide

XpertCreation is a platform from Lahore for people everywhere. Learn Microsoft Office, programming and languages with certificates, use more than seventy everyday tools, grow your network on XpertConnect, hire or work as a freelancer, shop from verified sellers, book a ladies-only ride, count your steps, join meetups, play games, find a blood donor, look after your pets and keep up with Pakistani and Indian dramas and films.

Almost everything is free. A few optional paid items help members get seen – boosts, the blue tick check, Company Pro and Store merchant plans. See [Promote and paid items](work/promote.md).

This guide explains each part of the site and how to use it. Start with [Your account](start/account.md) if you are new.
